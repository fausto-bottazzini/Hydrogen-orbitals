# Visualización de Orbitales del Átomo de Hidrógeno
Cálculo numérico y visualización de las densidades de probabilidad de los orbitales de un átomo de hidrógeno para diferentes valores de números cuánticos (n,l,m). 
Se calculan las densidades en 3D y se grafica en dos planos perpendiculares en los angulos seleccionados.

## Características
- Resolución de la parte radial de la función de onda.
- Implementación de Armónicos Esféricos.
- Generación de gráficos 3D de nubes de probabilidad y mapas de densidad 2D.

## Código utilizado
- **Python** (NumPy, SciPy para el cálculo matemático).
- **Matplotlib** (para la generación de los gráficos).

## Cómo ejecutarlo
Solo necesitas tener instalado Python y las librerías mencionadas. Ejecutá el script principal y por consola se controla que gráfico mostrar, se abrirá una ventana con el orbital configurado (n, l, m, φ, θ).
